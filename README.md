# Soft Cat — 3D engineering explorer

Interactive 3D model and engineering documentation for **Soft Cat**, a concept for an autonomous AI companion robot shaped like a cat. Interface in Russian, English and Bulgarian.

Live: https://soft-cat-explorer.vercel.app (`?lang=ru`, `?lang=en`, `?lang=bg`)

## Что внутри

- Процедурная 3D-модель (Three.js) из отдельно выбираемых компонентов: голова, шея, уши, шасси, 4 ноги × 3 привода, хвост, сенсоры, электроника, батарея, подогрев.
- Режимы A–G: изделие, прозрачный, инженерный, разнесённый, движение, сенсоры, материалы.
- 19 демонстраций движения, ручное управление степенями свободы, реакции на касание.
- Документация: BOM (прототип и серия), материалы, осуществимость и риски, энергобюджет, габариты и компоновка, архитектура ИИ, безопасность и приватность, производство и сервис.
- Экспорт: GLB, JSON-спецификации, BOM CSV, PNG, Markdown-сводка.

Все размеры, массы, мощности и цены — инженерные оценки или концептуальные допущения. Геометрия процедурная, не CAD. Анимации авторские и не доказывают механическую осуществимость.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Шаблон страницы (разметка с `{{…}}`, `sc-for`, `sc-if`) |
| `app.js` | Данные модели, сцена Three.js, анимация, логика интерфейса |
| `runtime.js` | Мини-рендерер шаблона на Preact |
| `i18n/ru.js`, `en.js`, `bg.js` | Все тексты интерфейса и документации по ключам |
| `tools/check-i18n.js` | Проверка, что во всех языках одинаковые ключи |

Сборка не нужна: это статический сайт. Three.js r128 и Preact 10 подключаются с jsDelivr.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Как править тексты

1. Найдите строку в `i18n/ru.js` и запомните её ключ (`s123`).
2. Измените значение с этим ключом в `ru.js`, `en.js` и `bg.js`.
3. Проверьте:

```bash
node tools/check-i18n.js
```

Новая строка — новый ключ во всех трёх файлах; в коде она вызывается как `U('s123')`, в шаблоне — как `{{L.s123}}`.

## Публикация

Сайт развёрнут на Vercel. После подключения репозитория к проекту `soft-cat-explorer` каждый push в `main` публикует production, а pull request получает отдельную ссылку предпросмотра.
